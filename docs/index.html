WINDOWS-FIRST STORAGE WORKSTATION

WINDOWS STORAGE ANALYZER

A local-first, explainable disk-space analyzer for Windows.

What is here now

  • Rust recursive filesystem scanner with JSON output.
  • Tauri/React Windows shell with a native scan_directory command bridge.
  • Browser-safe folder preview with the same summary presentation contract.
  • Regression tests, CI, documentation, and the verified v0.1.2 source release.

Where it is going

Windows installer bundling, cancellable scans, fast NTFS scanning, treemaps, duplicate analysis, safe cleanup, snapshots, reports, scheduled scans, Explorer integration, and remote-source adapters.
