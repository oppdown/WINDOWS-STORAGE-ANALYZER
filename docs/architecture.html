Architecture

Product boundary

WINDOWS STORAGE ANALYZER is a native Windows desktop application. The UI is a Tauri/React shell; authoritative scan, index, search, and file-operation logic lives in Rust.

Current native boundary

The desktop shell invokes the Rust scan_directory command with a user-entered path. Rust performs the read-only traversal and returns a camelCase JSON ScanResult containing the root node, nested children, byte totals, timestamps, and error count. The browser preview uses the same presentation contract with user-selected files.

Data flow

User target -> radio scan profile -> Tauri invoke(scan_directory) -> Rust safe traversal -> deterministic ScanResult tree -> React summary, folders, and largest-file views -> cancellable scan jobs -> SQLite index/snapshot -> filters/search/visuals/reports -> explicit file operation

Safety

Scanning is read-only. Move, delete, archive, and recycle actions will require previews, permission checks, collision handling, and confirmation. Remote connectors and telemetry are opt-in.
