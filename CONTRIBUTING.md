# Contributing

1. Keep changes focused and preserve unrelated work.
2. Run `cargo test --workspace` and `npm test` from `apps/desktop` before opening a pull request.
3. Add a regression fixture whenever scan totals, filtering, sorting, or file-operation behavior changes.
4. Do not add real user paths, file names, credentials, API keys, or private scan results to fixtures.
5. Use conventional commit subjects and update `CHANGELOG.md` for user-visible changes.

By contributing, you agree that your contributions are provided under the MIT license.
